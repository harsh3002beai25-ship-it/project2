# CINÉRA Next — TMDB Edition

## Run
1. Install Node.js 18+.
2. Copy `.env.example` to `.env`.
3. Put your TMDB **API Read Access Token** in `VITE_TMDB_READ_TOKEN`.
4. Run:
   npm install
   npm run dev

TMDB's API supports Bearer-token application authentication. The project uses the `/trending`, `/movie/*`, `/discover/movie`, `/search/movie`, and genre endpoints.

## Included
- Real TMDB movie data
- Trending, popular, top-rated and now-playing rows
- Live search
- Genre filtering
- Sort filtering
- Pagination
- Movie details + credits + YouTube trailer
- Responsive premium mobile navbar
- Local login/signup demo
- Persistent watchlist
- Loading skeletons
- Framer Motion UI
